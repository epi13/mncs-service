# MNCS language pressure ledger

Record workload, observed behavior, required semantic, reproducer, owner, workaround and closure verification.

## Initial pressure targets

- structured task scopes and join/cancel semantics
- ownership across async tasks
- deterministic resource cleanup/finalizers
- bounded typed channels/queues
- cancellation-safe awaits
- deadlines and monotonic clock APIs
- virtual/test clocks
- typed retry/error classification
- dependency/resource graph ergonomics
- configuration schema/default handling
- async test determinism
- introspection/evidence for running tasks and resources
